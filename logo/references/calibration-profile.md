# Calibration profile

Principles distilled from **14 rounds** (168 practice marks, human scores).

**Golden rule:** this file describes **how to build**, never **which noun to use**. The
product's brief (`must_read_as`, `specific_referent`) is sovereign. A high score on a practice
mark does **not** authorise reusing that shape on another product.

## What the calibration proved

| Fact | Evidence |
|------|----------|
| The quality bar is high | Most marks score 1–2; 3 is an acceptable direction; 4+ is rare |
| Immediate reading beats abstraction | Clock dial (4); crosshair (3, across three rounds); classic shield (4) |
| Copying a winning shape outside its brief fails | A canopy scored 1 in one brief and 2 in another — same shape, wrong noun |
| Stacked primitives always fail | Rectangle + triangle + rectangle scored 1 in every round |
| A beam glued to a rectangle is an AI tell | `beam-wrong` scored 1 consistently |
| A lone dot or circle is generic | `dot-only`, generic pin: 1 |
| An isolated hub/node with no silhouette is weak | `node-hub` reached 3 once; 1 in most rounds |
| A partial metaphor is not enough | A house drawn for a bridge brief (3); a tree for a branch brief (3) — wrong object |
| Lettermark plus ornament scores 1 | Letter shapes with a bolted-on detail |
| Abstract void or wedge with no gestalt scores 1 | `tick-wedge`, `disc-spoke`, `cone-void` |

## Construction principles (apply to any brief)

1. **Stranger first** — draw so a stranger names the brief's noun without reading the name. If
   it needs explaining, the ceiling is 2.
2. **Classic silhouette of the noun** — when pictorial, use a recognisable outline, not an
   abstraction that "suggests".
3. **One path, detail by void** — a single silhouette with `evenodd`/clip; never three or more
   loose primitives.
4. **Any second cue must be fat** — if a detail exists, it has to survive 24px or it does not count.
5. **Sector defaults only when they read instantly** — a circular clock passed at 4; a
   lighthouse-plus-beam, a four-point compass rose and a stock leaf are anti-references unless
   the execution is exceptional.
6. **Separate craft from context** — high craft on the wrong noun teaches technique; it does not
   authorise copying the shape.
7. **Check 96 / 48 / 24 px** before showing anything — detail that disappears caps the score at 2.

## Families that tend to score 3+ (when the brief asks for that noun)

Use as **grammar**, never as a fixed template:

| Brief asks for | Construction that tended to 3+ | Avoid |
|----------------|-------------------------------|-------|
| Time / clock | Circular dial + simple hands | A box with an abstract void |
| Target / aim / focus | Crosshair or concentric rings with a centre | An isolated dot |
| Signal / pulse / radar | Wifi arcs, or a wedge inside a disc | A triangular beam glued on |
| Shield / protection | Classic heraldic silhouette | A generic circular badge |
| Vector / direction | A fat arrow with a single body | A map pin |
| Compass / north | Disc + a north notch | A four-point compass rose |
| Architecture / cover | A roof with 3–4 legible verticals | Two posts (reads as pi) |

## Confirmed anti-patterns (recurring score of 1)

- Reusing a calibration mark while ignoring the brief
- An architectural formula copied because it once scored well
- A lighthouse with a glued triangular beam
- Stacked primitives with no authored path
- An ornament bolted onto a lettermark
- Loose dots standing in for a path
- A thin zigzag that vanishes at 24px
- A generic U shape — unless the brief genuinely asks for a cup or a trough
- An invert/recolour variant shipped to fill a quota

## How the skill uses it

- Read this **before** choosing a construction
- The brief defines the noun; this profile defines **execution quality**
- Never: "shape X scored 5 in a round, so I will use shape X here"
