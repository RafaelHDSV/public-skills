# Ambiente e operação

> **Para que serve:** instalar as skills.
> **Fonte da verdade:** README e CLI `skills`.
> **Relacionados:** [context](context.md)

```bash
npx skills add RafaelHDSV/public-skills --skill logo
npx skills add RafaelHDSV/public-skills --skill branding
npx skills add RafaelHDSV/public-skills --skill frontend-design
npx skills add RafaelHDSV/public-skills --skill readme
npx skills add RafaelHDSV/public-skills --skill ui-audit
npx skills add RafaelHDSV/public-skills --skill daily-standup
npx skills add RafaelHDSV/public-skills --skill cherry-pick-env-prs
npx skills add RafaelHDSV/public-skills --skill pr-review
```

Instale `logo` junto com `branding`. `readme` combina com `logo` (lockup). `ui-audit` combina com `frontend-design` (auditar → corrigir). Sem GitHub, aponte o agente a esta pasta ou copie para `~/.cursor/skills/` / `~/.claude/skills/`.
